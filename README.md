# Azpire Advisory Website

![License: MIT](https://img.shields.io/badge/license-MIT-green) ![Next.js](https://img.shields.io/badge/Next.js-16-black) ![React](https://img.shields.io/badge/React-19-61dafb) ![Tailwind CSS](https://img.shields.io/badge/Tailwind-4-38bdf8) ![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6)

Marketing site for Azpire Advisory, an accounting, tax and advisory firm serving SMEs in the UAE. It covers services, solutions, an about/team page, certifications (Xero, QuickBooks Online), FAQ and contact details.

## Getting Started

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm start
npm run lint
```

## Structure

```
src/app/          Routes: home, /about, /solutions, /contact
src/components/   Page sections (Hero, Services, Process, FAQ, ...)
src/components/about/  About page sections
src/components/ui/     Logo and animated background
public/           Logo and certification images
```
